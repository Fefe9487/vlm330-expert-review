# 照片危害辨識標註指引

給 A01–A11。每人只審自己的 30 張，四項都是整張照片的判斷，不用逐條法規、逐則案例各打一次分數。

法規是否適用，以 **2026-10-08** 當時有效的版本為準。

## 開始

1. 打開分給你的網址（網址結尾是 `?expert=A01` 到 `?expert=A11`）。
2. 確認畫面上的代碼是你的。代碼用來分開 11 份進度，沒有帳號密碼。
3. 用同一套瀏覽器做到完。清除網站資料會刪掉還沒匯出的評分。
4. 右上角「審閱說明」是簡表。判斷基準以本文件為準。

## 先看照片，再看 AI

左欄是照片和四項判斷，右欄是 AI 寫的內容。先看照片，自己想現場有什麼，再讀右側，最後才選。

- 點照片可放大、拖曳。
- 右側「信賴度」是 AI 對自己的把握，不是這項危害成立的證據。
- 「有／無立即危險之虞」、個人防護具、改善建議沒有單獨的分數。明顯不合理時，寫在補充意見。

## 1. AI 辨識的危害是否正確？

看危害類型和情境理由是否對得上照片，以及有沒有把推測寫成已經發生的事實。

| 選項 | 什麼時候選 |
| --- | --- |
| 正確 | 這張列出的危害和理由都對得上照片 |
| 部分正確 | 有的對、有的錯，或理由寫得比照片能支持的更多 |
| 不正確 | 主要危害或理由和照片不符 |
| 資訊不足 | 照片看不出判斷所需的事實，例如是否帶電、化學品成分、距離、會不會爆炸 |

選「部分正確」或「不正確」時，勾出有問題的危害；整體描述也不對時，勾「AI 整體描述」。可複選。勾了之後，該項下方可以寫這項的問題。「查看」會跳到那段原文。沒勾到的項目不會被當成你已確認正確，所以有問題的請勾上。第 3、4 項勾法規或案例時也一樣。

選「不正確」或「不適當」時，至少要勾一項，而且每一項都要寫原因，不能只勾選。空白或只打空白不能提交。選「部分正確」或「部分適當」時，原因可以留空。

選「資訊不足」或第 2 項的「無法判斷」時，該項下方要寫原因，說明看不出哪一項事實。沒寫不能提交。最下方的補充意見不能代替這段說明。

危害卡若寫「最終報告增列此類型，原始辨識結果沒有對應的情境理由」，這項是後來加上的，沒有原始辨識理由。照片上看不到，就計入辨識錯誤。

## 2. 是否已找出所有危害？

只算照片上能看出、而最終危害清單沒有的項目。

| 選項 | 什麼時候選 |
| --- | --- |
| 未發現漏報 | 看得到的危害都已出現在最終清單 |
| 有漏報 | 照片上還有清單沒寫的危害 |
| 無法判斷 | 照片不足以確定還有沒有漏。選了之後要在下方寫原因 |

選「有漏報」後，按「＋ 新增漏報項目」。類型從下面 17 種選一種，情境或位置可以留空；同一類型、不同位置請分成兩筆。開了空白列卻沒選類型時無法提交，請選類型或按「移除」。

墜落、滾落；跌倒；衝撞；物體飛落；物體倒塌、崩塌；被撞；被夾、被捲；被切、割、擦傷；踩踏（踏穿）；溺斃；與高溫、低溫之接觸；與有害物等之接觸；感電；爆炸；物體破裂；火災；不當動作。

頁面最下方「原始辨識的其他情境」，是前面辨識過、卻沒有進入最終清單的內容。那些內容照片看得到、最終清單沒有，算漏報，補登在這一項。

改選別的選項時，已寫的漏報會留成草稿，選回「有漏報」可以繼續改。

## 3. 引用法規是否正確且適用？

只評畫面上「引用法規」那一欄：名稱、條號、條文，以及是否適用這張照片的場所和作業。AI 貼的條文可能有錯，請用旁邊的官方法規連結核對。

| 選項 | 什麼時候選 |
| --- | --- |
| 適當 | 引用的條正確且適用，照照片該引的也有寫出條號 |
| 部分適當 | 同一張裡，有的危害引用正確，有的錯誤、不適用或沒有條號 |
| 不適當 | 引用錯誤、明顯不適用，或照照片應引用卻沒有條號 |
| 資訊不足 | 照片不足以判斷該引哪一條 |

下面這些都算**沒有引用**：空白、畫面顯示「AI 未引用法規」，或內文是「無指定法規」「無」「未提供」「未提供路由法規」「未提供特定法規條文」「無參考法規」。

照片足以對上應引用的法規時，選「不適當」，勾該危害那一列，並勾「缺少應引用的法規」。同一張有的有條號、有的沒有，選「部分適當」，只勾沒寫或寫錯的那些。

「無直接證據，請現場人員確認。」出現在改善建議，不是法規。這句不能代替條號。危害本身是推測時，回到第 1 項處理。

補充意見可以寫哪一條不適用，或少了哪一類法規。不用貼條文全文。

## 4. 職災案例是否適當？

看案例的作業情境和致災機制，能不能支持這張照片的危害。這些案例沒有原始出處，無法核對是不是某一次真實事故的原文。

| 選項 | 什麼時候選 |
| --- | --- |
| 適當 | 作業和致災過程對得上這張照片的危害 |
| 部分適當 | 同一張裡，有的案例對得上，有的對不上 |
| 不適當 | 作業、設備或致災過程和照片的危害對不上 |
| 資訊不足 | 案例太短或太籠統，無法確認是不是同一類事故 |

案例內文若是「無參考職災案例」，這不是一則可用案例。整張都是這句，選「不適當」。只有其中幾則是這句，選「部分適當」，並勾那幾則。

畫面上若寫「AI 未提供職災案例，本項免評」，這張不用評第 4 項。

## 補充意見

選填，5,000 字以內。這欄是整張照片的補充，例如漏了右側電箱、改善建議或立即危險判斷不合理。選「不正確」或「不適當」時，原因要寫在勾選項目下方，不能只寫在這裡。

## 送出與回傳

1. 四項都選完後，按「提交並繼續」。最後一張是「提交並完成」。
2. 已提交的照片可以按「重新開啟評分」再改，改完再提交。
3. 做完、或要換電腦之前，到「我的進度與備份」，按「匯出 JSON 評分檔」。
4. 把這份 JSON 回傳。CSV 只供統計，不能還原你的進度。
5. 換裝置時，先按「匯入評分備份」，選自己的 JSON，再繼續。

頂部「已提交 x / 30」到 30，才算這一份完成。草稿不算完成。
