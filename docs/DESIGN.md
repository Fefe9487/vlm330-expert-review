# 專家評分工作台

主要使用者是 A01–A11 共 11 位專家。每位預設審閱全部 330 張，直接看修訂版照片及 AI 最終報告。成功是能逐项判斷危害、法規、案例，補記漏報，保存並匯出。

桌面採任務清單、照片及評分三區。照片保持可見，法規與案例逐步展開。手機先照片再評分，任務清單收合。參考 GitHub Primer 的清楚狀態、Carbon 的表單層次，以及 Label Studio 的圖片／評分鄰近原則。

頁面使用繁體中文、深綠強調色及低彩度背景。字級至少 14px，點擊區至少 36px，主要提交鈕和保存狀態清楚分開。狀態同時有文字，不能只靠顏色。避免行銷大標、裝飾圖表和將 JSON、路徑或設計說明放在主要頁面。

所有評分初始為空。負面判斷有勾選理由，資訊不足獨立記錄。案例來源尚未確認，不能將 AI 條文當官方答案。正常項目可由專家明確點選快速標記，不能自動預填正確。

進度只存在本瀏覽器；保存成功以 IndexedDB transaction 完成為準。切換照片及專家先完成保存。備份綁定資料集版本、照片雜湊與專家；管理者可在本機匯入 11 份檔案彙整，沒有線上共用評分庫。資料代碼是進度識別，不是登入或存取限制。

驗證：330 筆圖文完整性；不同專家隔離；刷新還原；未完整不得提交；長內容、圖片放大與窄螢幕；備份還原、衝突及 CSV 安全；抽驗至少五個真實案例。QA 操作使用獨立儲存空間，不產生正式專家評分。
