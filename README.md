# VLM330 照片危害辨識專家審閱

供 **11 位專家（A01–A11）** 直接對照 330 張照片及 AI 結果，評估危害、引用法規、事故案例、改善建議、防護具與危險程度，並補記漏報。每位預設審閱全部 330 張。

網站可直接在 GitHub Pages 運行，沒有 npm 套件或外部 CDN 依賴。評分只存在各自的瀏覽器 IndexedDB，**不會自動傳回 GitHub 或共用資料庫**。

## 專家使用

1. 選擇分配給你的代碼；直接看照片及 AI 報告。
2. 逐項判斷。「部分正確／不正確／不適當」時勾選理由，或補一句說明。資訊不足另外記錄。
3. 確認整張照片有沒有漏報；有漏報時勾選危害類型，必要時補充位置。
4. 點「提交本張，繼續下一張」。欄位未完整時會提示；提交後仍可修改。
5. 定期到「我的進度與備份」匯出 JSON。審閱完成後回傳 JSON；換裝置時匯入恢復。CSV 可閱讀及統計，不能還原。

專家代碼是進度識別，並非帳號登入或網站存取限制。請自行確認代碼。照片與 AI 報告在公開網站可被查看；專家評分檔不包含在 repository。

## 收集 11 位專家的結果

在「評分檔彙整」選取專家回傳的 JSON 檔，可以一次匯入多份。匯入前核對資料集版本、專家代碼、照片雜湊及引用項目。重複匯入不會增加同一專家的同一張照片筆數；預設只補入本機沒有的答案，可明確選擇更新較新的版本。

彙整區顯示 11 位專家的提交數、草稿、漏報照片及危害判定數，並可匯出全部 CSV 明細與彙整 JSON。草稿不計入判定數；資訊不足另列。不同專家的分歧答案保留，沒有自動把多數意見當作最终裁定。

## 評分內容

- 危害：正確、部分正確、不正確、資訊不足。
- 法規：逐條評估名稱／條號／全文與情境適用性；查閱 AI 附帶全文並連結官方來源。未引用法規時，可判斷是否應補充。
- 案例：評估情境與致災機制的適切性。原始案例來源目前未確認，不能據此宣稱摘要已查證。
- 改善、防護具：適當、部分適當、不適當、資訊不足。
- 立即危險：合理、不合理、資訊不足。
- 漏報：未發現漏報、有漏報、無法判斷；提供危害清單與選填說明。

所有選項起始為空。快速標記只會在專家主動點選「本項內容均適當」等按鈕時執行；既有補充說明不會被刪除。

## 資料

資料集 `vlm330-20261008-7396811ccfe0`：營造 219 張、製造 111 張，合計 330 張。AI 最終報告包含 1,285 個危害項目與 2,375 段案例摘要。採用使用者指定的修訂版照片，不使用尚未同步的舊索引。330 張原圖按原始位元組複製，沒有裁切、旋轉或重新壓縮。

`data/manifest.json` 保存每張照片的 ID 與 SHA-256；`data/cases/` 保存各張報告；`assets/photos/` 保存原图。原始 Excel 與整個分析工作區沒有放進此 repository。

法規判斷建議以 2026-10-08 有效版本為基準。修正日期與施行日期需分別確認。[官方法規](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0060009)

## 本機啟動與檢查

需要 Node.js 20 以上，不需 `npm install`。

```sh
npm start
```

開啟 `http://127.0.0.1:8133`。GitHub Pages 的專案子路徑亦支援。

```sh
npm test
python scripts/validate_site.py
```

`?qa=1&expert=A11` 使用獨立測試儲存空間，匯出檔帶 `_QA` 標記；不影響正式資料。正式評分請不要使用 `qa=1`。

重新產生資料僅在手上有來源 Excel 與修訂版照片時需要。安裝 `openpyxl` 後執行：

```sh
python scripts/build_dataset.py --workbook /path/to/results.xlsx --images /path/to/revised-images
```

來源目錄需有 `營造/` 與 `製造/` 子目錄；結果與照片不完全對應時會中止。資料版本由來源與照片雜湊決定，版本改變時不會混用既有評分。

## GitHub Pages

在 repository 的 **Settings → Pages**，選 **Deploy from a branch**，來源為 `main`、`/(root)`。已有 `.nojekyll`，不需 build 或 server。GitHub Pages 提供靜態網站；評分與備份仍在使用者瀏覽器。[GitHub 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages)
